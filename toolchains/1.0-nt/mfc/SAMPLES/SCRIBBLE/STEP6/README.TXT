Chapter 10 of the Class Library User's Guide presents SCRIBBLE Step 6,
where you add context-sensitive help support to SCRIBBLE.  Unlike SCRIBBLE 
Steps 0 thorugh 5, no sources other than PEN.RTF are provided for Step 6
for reasons of diskspace economy.  

If you want to try out the framework's context-sensitive help support without
following the Step 6 instructions in Chapter 10, then follow these simple
instructions:
(1) Run AppWizard, using the Context-Sensitive Help option in the Options
	dialog.
(2) Build the application produced by AppWizard.
(3) Run the application.  Use the F1 and Shift-F1 keys.

If you would like to build Step 6, then follow the tutorial instructions
in Chapter 10.  To save you the effort of authoring the help topics
specific to SCRIBBLE, we provide the Rich Text Format file, PEN.RTF, which
is the only file in this directory (other than this readme.txt).
Chapter 10 explains how to use PEN.RTF in conjunction with the other RTF
help source files produced by AppWizard.
