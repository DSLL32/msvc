Briefly, GIB is a stand along programmer toolkit.  It allows a software developer
to design, test, and generate a completely functional graphical user interface
all without typing a single line of programming code.  GIB takes the unique approach
of allowing a designer to create the user interface by drawing & painting rather than
by programming.  The action editro enables the designer to assign an arbitrary action
(behavior) to a graphical object.  The prototyper provides a quick on-line design
feedback, and the code generator generates the interface control program in popular C
code.  The only programming effort left is link and compiler your application dependent
codes with this generated interface control program.

The GIB package is composed of three major components: an action/graphic editor, a
run-time graphics kernel, and a graphic programming library.  There is no royalty charge.
Currently, there are three products in the GIB family:
          (a)  GIB/3.0: for DOS real mode C programming.
          (b)  GIB/MMCD: for Sony Multimedia CD-ROM System, real-mode C programming.
          (c)  GIB/Premier: for DOS protected- or 32-bit mode programming.

Objects Only, Inc.
11919 N. Jantzen Avenue, Suite 257
Portland, OR  97217

Directory: OBJSONLY

SYMSCAN is a smart object-code grep utility.  It is indispensable for
diagnosing link errors -- unresolved externals, duplicate symbols,
segment and group overflows, etc.  SYMSCAN is also useful for
learning about large bodies of unfamiliar code; it has the speed and
convenience of grep, but provides better information because it
parses .OBJ and .LIB files. It distinguishes symbol references from
definitions and identifies exactly WHERE in each module the
definition/reference occurs.  Locations are shown by function name or
even source-line number if debug information is present. SYMSCAN
shows true sizes for every type of program object.

Execute symscan.exe with no arguments to get usage instructions.
Execute it with a -xhelp argument and redirect the output to a file
to get full documentation.
