Rational Rose Demonstration


Rose enables the members of a development team to use object-oriented technology more effectively.  Rose is used to represent, verify, and communicate the architecture of an object-oriented software system. Rose provides a single product on Windows and UNIX. 

Rose provides representation features :
- Intuitive, easy to use,  UI and drawing capabilities
- Fine-grained specifications
- Querying mechanisms
- Booch compliant notation support

Rose provides verification features :
-  Semantic checking 
	
Rose provide communication features :
-  Printing mechanisms
-  C++ Code generation (with CodeCycle/C++)

This demonstration presents Rose 1.0.7, our Analysis and Design best selling tool, used at more than 2500 sites today.
