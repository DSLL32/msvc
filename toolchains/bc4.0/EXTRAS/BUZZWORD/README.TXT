                                    WinGEN

WinGEN is an object-oriented WYSIWYG source code generator / data entry
design tool and converter of ObjectVision .OVD files to Windows 3.1 versions
of dBASE, C/C++, and Borland Pascal.  WYSIWYG text, buttons, colors, and other
object properties enable creation of advanced interactive Windows database
applications.  OLE and DDEML links are supported.  Available for Windows 3.1,
OS/2 2.1, Windows NT, and Unix System V Release 4.

In this directory you will find a file called WinGEN.EXE.  This file is a
self-extracting .ZIP file containing the demonstration version of the
WinGEN Screen Designer package.  To run this demonstration you will need to
create a directory on your hard drive.  From the C> prompt you will need to
change directories to the directory you have just created and then run the
WINGEN.EXE file from the CD-ROM.  Or to illustrate:

    C:\> MD WinGEN
    C:\> CD WinGEN
    C:\WINGEN> E:WINGEN.EXE

Note that this example assumes that the file WINGEN.EXE is located in the
current directory on your CD-ROM and that your CD-ROM drive letter is E:.
