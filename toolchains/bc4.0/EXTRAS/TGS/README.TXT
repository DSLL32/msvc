FGDEMO is a grand-tour demo program showing the features of Fastgraph(tm)
programmer's graphics library. It features a GUI interface, mouse support,
animation and special effects. 

Fastgraph is a high-performance graphics library that originated as a
game library but has the general-purpose functionality to support the
most robust DOS graphics applications. The highly optimized functions 
support 25 video modes including SVGA and the popular "mode X".

Source code for the demo is available, as is a shareware version of 
Fastgraph. Contact TGS at (702) 735-1980 for more information.
