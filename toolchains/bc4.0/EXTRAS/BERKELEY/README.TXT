Welcome to the world of reuseable software components.  In this
demonstration program, you will find a library of objects for
building manufacturing applications.  Using a windows interface, you
will be able to examine these objects, and evaluate whether they meet
your application needs.  

To load the demo diskette from drive a: to drive c: 
run the following commands:
	mkdir c:\bpg
	cd c:\bpg
	pkunzip a:\blocks.zip

To understand the product read the included article article.txt.  If you want 
more information then read manual.txt.

To run the windows demonstration program please type the following:
	win blocks
