Program logic is C, including argument parsing, option processing, the driver,
COMDAT allocation, mapped-file/cache handling, COFF readers, module/library and

remain separate at the original graph boundaries. Source declarations recover

assembly ABI exception. INT3 in pending stubs is part of the required workflow.

Determine that extent when the stub is reached before accepting its C body.

Internal C layouts belong to this reconstruction. ImageOptions models named
settings rather than preserving unused original-layout slots. FileSlot, Page,
Contribution, Module, Library, Section, Group, symbol tables, and enumerators
have contextual types and named fields. Some unreached consumers still need

the target platform's file-format layouts. The DOS message program is output
file data, described by fields; it is not an execution mechanism for LINK.

Data is defined with its owner. There are no original section snapshots or
anonymous image arrays. Ordinary strings occur at use sites. The two named
ordinary string arrays are sentinels: pass one compares output_name against
coff.out by address, and the CVPACK launcher distinguishes its default program
object by address. Section-default records combine names and flags used by
multiple callers. The dispatch/help tables retain their actual table roles.
The debug-flags array ends at original 0005c06c, where independent Macintosh
state begins; it no longer doubles as storage for unrelated linker globals.

The original LIBC.LIB supplies verified static runtime routines. The matcher
checks COFF bytes and relocation targets, including external calls, and treats
same-address aliases as one vertex. Older CRT differences in the executable
have C equivalents in runtime.c. CRT globals such as _iob, _osfile, locale data,
and heap state use the linked library's named globals. crt-anchors.c requests
the original floating-point/termination members without copying library data.

The graph audit compares calls including indirect calls and tail calls. The
callback audit compares relocated function addresses embedded in each accepted
source routine, including enumerator methods and qsort/CRT callbacks. The data
audit checks named initial values and pointers; pointers to ordinary literals
are compared by string value where address identity is not significant.
These static checks complement execution, rather than proving every future path.
The instruction scanner recognizes switch tables both with scaled indexes and
with an index shifted before JMP [register+table], as emitted by /Od.

contributions, reference lists, final values, and undefined-list back links.

counter is shared by override handling and definition transitions. Hash nodes and
interned-name nodes draw from the retained small-allocation pool; this is mutable
allocator state, not copied executable data. The streaming reader similarly owns
one typed, reusable IMAGE_SYMBOL object.
