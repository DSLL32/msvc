CVPACK process-boundary reference

hello-debug-dll/before.dll and after.dll are a fresh shared-prefix original
CVPACK transition. LINK computes its complete prepack input. Only an exact match
under declared structural clock fields permits the captured response. Unknown
commands/environment, changed non-clock input or nonempty child streams fail.
These are reference artifacts, not reconstruction implementation data.

The explicit capture uses R: original LINK/CVPACK, S: canonical cwd and the
original-only debugger in src/capture-original.c. Capture receipt/events pin
entry order, helper/tool hashes, exact invocation/status and empty child streams.
The packed response is71756bytes. Its clocks/checksum are modeled structurally;
no path or content bytes are replaced. The earlier boundary was independently
copied into CVPACK's owned case before this directory was superseded.
