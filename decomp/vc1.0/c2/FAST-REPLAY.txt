C2 historical replay
====================
Run commands from this binary directory. Reconstruction source is in src/;
Python and shell tooling is in scripts/. Build outputs, case metadata and
fixture paths retain their existing binary-directory-relative locations.

make replay and make hello-replay use the shared continuous walker by default.
The shared implementation is in the repository's tooling/replay/ directory.
For a fresh-start historical replay use REPLAY_METHOD=fresh, or run:
  python3 scripts/replay-frontiers.py --method fresh --profile minimal
  python3 scripts/replay-frontiers.py --method fresh --profile hello

Minimal replays acceptance indices [0,352), then requires exit:0. Hello restores
that accepted prefix and replays [352,current accepted length), then requires
its current still-masked named frontier. A fresh paired final run establishes
the terminal independently; acceptance metadata is never advanced by replay.

Each side has a private case directory and exact MSC_CMD_FLAGS-only child
environment, captured relative IR inputs, no extra backend arguments and its
preferred image base. The two independent walkers run concurrently and restore
complete indexed functions/shared text. Unsupported processes, threads, faults,
interior traps and unexpected exits fail; the shared runner retains context.

The adapter freezes originals, build/map/runtime indexes, acceptance metadata,
source/scripts, fixture manifest/input/expected-output files, and each plan,
masked image and copied input. The shared runner additionally freezes itself
and the debugger. Completed minimal runs validate their own 286-byte object,
empty streams and exact directory contents against the captured fixture,
ignoring only the four COFF timestamp bytes at offset 4. Existing fresh and
untouched-original output checks remain. Incomplete hello runs compare the
streams observed at the terminal; they do not claim a completed object.

Receipts and raw events are kept under ~/.ai-tmp/vc1.0-c2/fast-replay-<case>-<pid>.
--receipt PATH writes a convenient summary copy. To reproduce a divergent
absolute acceptance index N from clean state:
  python3 scripts/replay-frontiers.py --profile hello --stop-at N
  python3 scripts/replay-frontiers.py --profile hello --method fresh --stop-at N
The latter reruns the fresh history through N and stops with N still masked.
For a single focused fresh pair at N, use compare.compare(N) from scripts/compare.py.
Compare complete fresh and continuous receipts from the same frozen build with:
  python3 scripts/check-replay.py FRESH_RECEIPT CONTINUOUS_RECEIPT

Summary receipts record exact shared-source/helper hashes and phase timings:
initial setup, fresh final oracle, plan setup (with fixture-copy subset), helper
build/freshness check, fast pair, and output checks plus final hash verification.
Target compilation, prefix initialization and original fixture generation are
not performed by this command. See cases/fast-replay.json for measured adoption
runs, external process wall times, and explicitly unmeasured timing splits.

Fast replay checks first-encounter history and its terminal event; it is not
branch coverage. make frontier, make hello-frontier, specialized ABI/state
captures, graph/extent audits and make check retain their existing roles.
No new function is accepted using the continuous historical replay alone.

The earlier PAUSED.txt describes pending reconstruction, not this harness
adoption. Its scratch capture instructions predate the layout change: scratch
Python helpers that import compare/binary now need PYTHONPATH=scripts.
